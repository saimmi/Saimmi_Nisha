## Overview

A responsive, single-page portfolio with sections for skills, featured
projects, industry (virtual) experience, an about section, education, and
certifications. The design uses a warm editorial light theme with a
serif/sans type pairing.

**Tech:** plain HTML, CSS, and a small amount of vanilla JavaScript — no build
step or framework required. Fonts and icons are loaded from CDNs (Google Fonts
and Font Awesome), so an internet connection is needed for them to render.

## Run locally

Just open `index.html` in any browser. No server or install needed.

## Deploy with GitHub Pages

1. Make sure the main HTML file is named **`index.html`** (GitHub Pages serves
   this automatically as the homepage).
2. Create a repository and push these files:
   - For a **user site** at `https://<username>.github.io`, name the repo
     `<username>.github.io`.
   - For a **project site** at `https://<username>.github.io/<repo>`, use any
     repo name (e.g. `portfolio`).
3. In the repo, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*,
   choose the **`main`** branch and the **`/ (root)`** folder, then **Save**.
5. Wait a minute or two — the live URL will appear at the top of the Pages
   settings.

> Tip: keep the `images/` folder next to `index.html` and confirm the photo
> filename matches the `src` in the HTML exactly (web servers are
> case-sensitive).
