Customer Segmentation Analysis

Cleaned 525K raw e-commerce transactions down to 406K records (77.3% retained) using regex-based filtering, then built an RFM feature set and segmented 4,300+ customers into 7 actionable groups via KMeans with IQR outlier handling.
